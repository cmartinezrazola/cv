# 📄 Personal Curriculum Vitae

Personal Curriculum Vitae built with **[Typst](https://typst.app/)** — a modern, lightning-fast markup-based typesetting system designed as an alternative to LaTeX.

## 🛠️ Tech Stack & Tools

* **Typesetting Engine:** [Typst](https://typst.app/) (Rust-powered compilation)
* **Version Control:** Git & GitHub
* **Editor:** Visual Studio Code (with Typst LSP extensions)

---

## 📂 Project Structure

```text
.
├── assets/               # Static resources (icons, images, etc.)
├── cv.typ                # Main file containing the curriculum content
├── template.typ          # Reusable layout template (styles, typography, structure)
├── .gitignore            # Excluded files (local PDFs, compiler cache, editor configs)
└── README.md             # Project documentation and setup guide
```
